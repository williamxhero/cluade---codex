# 🎯 快速使用指南

## 🚀 最简单的使用方式

### Windows
```cmd
# 双击运行
sync.bat

# 或者命令行
sync
sync preview
sync to-claude
sync to-codex
```

### Linux/Mac
```bash
./sync.sh
./sync.sh preview
./sync.sh to-claude
./sync.sh to-codex
```

## 📝 常用命令速查

| 命令 | 说明 | 场景 |
|------|------|------|
| `sync` | 双向自动同步 | 不确定哪边改了，让工具自动判断 |
| `sync preview` | 预览模式 | 想先看看会同步什么 |
| `sync to-claude` | 同步到 Claude | 在 Codex 中新增/修改了配置 |
| `sync to-codex` | 同步到 Codex | 在 Claude 中新增/修改了配置 |
| `sync help` | 显示帮助 | 查看所有选项 |

## 🎬 使用场景示例

### 场景 1: 日常同步（最常用）
```bash
# 每天开始工作前运行一次
sync preview      # 先看看有什么变化
sync              # 确认后同步
```

### 场景 2: 在 Codex 中新增了技能
```bash
sync to-claude    # 同步到 Claude Code
# 然后重启 Claude Code
```

### 场景 3: 在 Claude Code 中修改了配置
```bash
sync to-codex     # 同步回 Codex
# 然后重启 Codex
```

### 场景 4: 不确定哪边有变化
```bash
sync              # 自动判断并双向同步
# 然后重启两个工具
```

## ⚡ 添加到系统 PATH（可选）

### Windows
```cmd
# 1. 复制工具目录路径
D:\WILL\AGENT\agent

# 2. 添加到环境变量 PATH
# 系统属性 → 环境变量 → Path → 新建 → 粘贴路径

# 3. 之后可以在任意位置运行
sync
```

### Linux/Mac
```bash
# 添加到 ~/.bashrc 或 ~/.zshrc
echo 'export PATH="$PATH:/path/to/agent"' >> ~/.bashrc
source ~/.bashrc

# 之后可以在任意位置运行
sync.sh
```

## 🔧 故障排查

### 问题：sync 命令找不到
**Windows**: 确保在 `D:\WILL\AGENT\agent\` 目录中运行，或添加到 PATH
**Linux/Mac**: 使用 `./sync.sh` 而不是 `sync.sh`

### 问题：Python 未找到
**解决**: 确保安装了 Python 3.6+，并在 PATH 中

### 问题：权限错误
**Windows**: 以管理员身份运行
**Linux/Mac**: 使用 `chmod +x sync.sh` 添加执行权限

### 问题：编码错误
**解决**: 工具已内置 UTF-8 修复，如果还有问题，检查终端编码设置
