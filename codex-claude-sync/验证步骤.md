**操作**: 在 Codex 中打开 Settings → Skills 页面
**问题**: Codex 中显示多少个技能？

**如果显示少数几个（<10）**:

→ 迁移完全成功，这不是问题

→ 说明 Claude Code 确实有问题
→ 需要继续调查
