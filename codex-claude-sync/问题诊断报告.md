## 可能的原因

### 1. Claude Code 需要重启（最可能）
Claude Code 在启动时加载技能配置。如果迁移后没有完全退出并重启，可能只识别了部分技能。

**解决方案**：
```
1. 完全退出 Claude Code（不是最小化，是退出）
2. 确保进程完全关闭：
   - Windows: 任务管理器检查 Claude Code 进程
   - Mac: Activity Monitor 检查
3. 重新启动 Claude Code
4. 等待几秒让它加载所有技能
5. 输入 / 查看技能列表
```

### 2. Claude Code 缓存问题
Claude Code 可能缓存了旧的技能列表。

**解决方案**：
```bash
# 清除 Claude Code 缓存（谨慎操作）
# Windows
rmdir /s /q "%APPDATA%\.claude\cache"

# Linux/Mac
rm -rf ~/.claude/cache
```

### 3. 技能加载路径问题
Claude Code 可能没有正确扫描 skills 目录。

**验证方法**：
检查 Claude Code 的日志文件（如果有）查看是否有加载错误。

### 4. 技能格式问题
虽然文件格式看起来正确，但可能某些技能的 frontmatter 有问题导致整个加载失败。

**验证脚本**：
```python
# 运行这个脚本检查所有技能的格式
python codex-claude-sync/verify-skills.py
```
